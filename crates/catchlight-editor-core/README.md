# catchlight-editor-core

Authoring tools over a Catchlight `Model`: mesh triangulation and automeshing,
model manifests, strand fitting, recording, and branching model history.

The library is wasm-safe and has no GPU, filesystem, or asynchronous runtime
dependency. Use it to embed authoring logic in an application.

```sh
cargo add catchlight-editor-core
```

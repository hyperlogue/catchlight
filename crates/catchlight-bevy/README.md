# catchlight-bevy

Bevy integration for Catchlight character animation. `CatchlightPlugin`
connects model assets, puppet components, and the render graph. Load a
`CatchlightModel`, spawn a `CatchlightPuppet`, and render through a
`CatchlightCamera`.

This release targets Bevy 0.19. The integration is also available as
`catchlight::bevy` with the `bevy` feature.

```sh
cargo add catchlight-bevy
```

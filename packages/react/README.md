# @catchlight/react

React 19 hooks and unstyled components over `@catchlight/core`.
Use `EditorProvider` to supply an editor, then compose session hooks and editor
parts. Install React and `@catchlight/core` as peer dependencies.

```sh
npm install @catchlight/react
```

# @catchlight/core

Web-platform glue for Catchlight editor sessions, backends, storage, and viewports.
The host supplies an initialized WASM module through the `WasmModule` interface;
this package does not bundle WASM. `@catchlight/core/fakes` provides test doubles.

```sh
npm install @catchlight/core
```

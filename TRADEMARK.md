# Trademarks

"Catchlight" and the catchlight logo ([assets/logo.svg](assets/logo.svg))
are the project's marks. The code licences grant rights in the code and none
in the marks: Apache-2.0 section 6 says so outright, and the MIT option is
silent, which comes to the same thing.

Forks and redistributions may state what is true — that they are built on
catchlight, derived from it, or compatible with it. They may not take the
name or the logo as their own, or use either in a way that suggests this
project endorses them.

Marks named elsewhere in this repository — Inochi2D, and every other product
the docs name — belong to their owners and appear descriptively, to say what
catchlight reads, matches or runs on.

# catchlight (Python)

The catchlight editor protocol as Python dataclasses.

`catchlight/protocol_gen.py` is generated by `cargo xtask generate python` from
`crates/catchlight-editor-protocol` and committed; `cargo test -p xtask` fails
if it has drifted. Do not edit it — change the Rust types and regenerate.

```python
from catchlight import CommandKind, NodeAdd, NodeKindArg, parse_reply

command = NodeAdd(session=1, parent="root", kind=NodeKindArg.PART, name="Body")
assert command.KIND is CommandKind.DOCUMENT
request = {"id": 7, **command.to_wire()}
```

There is no transport here. A caller sends `request` as one JSON line and hands
the answer to `parse_reply`.

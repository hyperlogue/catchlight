# catchlight (Python)

A blocking client to `catchlight-editor-server`, and the editor protocol it
speaks. Pure Python, no runtime dependencies, no Rust linked: the server's
reader is the only validation there is, which is the point — a model this
package writes is a model the editor wrote.

```python
import catchlight

with catchlight.launch() as server:
    client = server.client()
    session = client.new("Doll")
    part = client.add_part(session, name="Body")
    client.add_texture(session, part, "body.png")
    client.send(catchlight.MeshAuto(session=session, node=part))
    client.save_to(session, "doll.clm")
```

## The pieces

| Module | What it is |
| --- | --- |
| `protocol_gen.py` | Generated wire types. Never edited by hand. |
| `transport.py` | One `request` interface, two doors: the Unix socket and HTTP. |
| `server.py` | `launch()` starts an editor and owns it; `connect(url, token)` attaches to one it does not. |
| `client.py` | `Client.send` for any command, plus the handful of round trips that are more than one call. |
| `builder.py` | `Builder`: a group, a part, a param, a binding — one call each, over one session. |
| `layers.py` | The placement file the reference-image pipeline hands over, read and written. |

`protocol_gen.py` is generated by `cargo xtask generate python` from
`crates/catchlight-editor-protocol` and committed; `cargo test -p xtask` fails
if it has drifted. Do not edit it — change the Rust types and regenerate.

A field left `None` is left off the JSON entirely, which on this wire says
"unchanged". A few fields have to be able to say "nothing" as well, and those
are annotated `T | Clear | None`: pass the `CLEAR` singleton and `to_wire()`
writes a JSON null. `NodeSet(session=s, node=n, texture=CLEAR)` is how a part
is told to draw no texture at all.

## Two doors

`launch()` starts a server on a socket inside a fresh `0700` temp directory.
That directory mode is the whole of its access control, so there is no token,
and the socket never collides with the editor a person already has open. On
exit the process is terminated, killed if it lingers, and the directory
removed.

`connect(url, token)` attaches over the server's HTTP door instead, for an
editor something else is running. It never stops what it did not start. The URL
must name loopback: the token travels in clear text. A command there is one
`POST /request` carrying the very JSON object the socket carries, so there is
no connection to open and a wrong token surfaces on the first `send`.

What differs between them is where the bytes are. Over the socket the editor
reads the very filesystem the script is on, so a texture is a path and
`save_to` is a save. Over HTTP the editor's store is somewhere else, so a
texture is staged with `PUT /files/…` and then named, and `save_to` fetches the
document and writes it here. `Client` picks by transport; a script reads the
same either way.

Neither door hears an event. The editor pushes those over the WebSocket a
browser tab holds, which this package does not open; a blocking caller learns
its document moved from the `rev` on its own reply — `client.revision(session)`.

Over HTTP a status is this listener refusing the request — no token, a body
over the cap — and raises `TransportError`. A command the *editor* refused is a
200 carrying an `err` reply, which raises `ProtocolError` with the code to
branch on, exactly as it does over the socket.

## Commands

`Client.send` takes any command in the protocol and returns its reply body,
raising `ProtocolError` with an `ErrorCode` if the editor refused it. The
command's own `KIND` says what sending it does: `document` moves the session's
revision, `presence` and `scratch` move nothing, and the two query kinds read.

```python
from catchlight import MeshAuto, AutoMeshGrid, NodeTree

client.send(MeshAuto(session=session, node=part, mode=AutoMeshGrid(cols=4, rows=3)))
tree = client.send(NodeTree(session=session))
```

## Building a model

`Builder` is the imperative shape of the protocol. Every add returns the Id the
editor minted, and a `part` is complete when it returns — node, texture, place
and mesh are four commands and it sends all four.

```python
built = catchlight.Builder.new(client, "Doll")
head = built.group("Head", z=1.0)
face = built.part("Face", "face.png", parent=head, z=2.0, offset=(0.0, 0.4))
tilt = built.param("Tilt", min=-1.0, max=1.0, default=0.0)
built.bind(tilt, face, "ty", [(-1.0, -0.2), (0.0, 0.0), (1.0, 0.2)])
print(built.check())
built.save_to("doll.clm")
```

A binding's keys are param values, not cell indices: `bind` inserts the key
positions those values need and then indexes them, so a caller never computes a
cell. `check()` returns the editor's own lints and raises for none of them — a
part still to be meshed is a step not taken, not an error.

## Layers in, model out

A step outside this package turns reference images into one cut-out RGBA PNG
per part and one placement file beside them. `read_layers` reads that file and
`build_from_layers` turns it into a whole model.

```json
{
  "catchlight_layers": 1,
  "layers": [
    {"name": "Head", "z": 1},
    {"name": "Face", "file": "face.png", "parent": "Head", "z": 2,
     "offset": [0.0, 0.4], "opacity": 1.0,
     "mesh": {"mode": "grid", "cols": 4, "rows": 3}}
  ]
}
```

`name` and `z` are the only required fields; `z` is draw order the way the
protocol means it, higher in front. A layer with no `file` is a group, a `file`
is a sibling of the placement rather than a path, a `parent` is declared before
its children, and `mesh` is an `AutoMesh` exactly as `to_wire()` emits it —
absent, the editor traces the alpha itself.

```python
built = catchlight.build_from_layers(client, "layers.json")
built.save_to("doll.clm")
print(built.problems)  # the closing check(), reported rather than raised
```

## Tests

```
cargo build -p catchlight-editor-server
cd python && uv run pytest -q
```

Each test launches its own server. `launch()` finds the binary from its
`binary` argument, then `$CATCHLIGHT_EDITOR_SERVER`, then `PATH`, then this
workspace's `target/debug` build — which is why `cargo build` above is the only
setup. One test waits out the editor's 30 s socket timeout for real; skip it
with `-m "not slow"`.

Unix-only, because the socket is.
